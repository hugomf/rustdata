# rustdata

Spring Data-style generic CRUD and query repositories for [sqlx](https://github.com/launchbadge/sqlx), with a
multi-dialect SQL transpilation engine.

## Crates

| Crate | Description |
|---|---|
| [`rustdata-core`](crates/rustdata-core) | Generic CRUD repository, dialect engine, `#[derive(Entity)]` / `#[derive(QueryMethods)]` macros, soft-delete, pagination, specification pattern. Supports **PostgreSQL**, **SQLite**, and **MySQL**. |
| [`rustdata-macros`](crates/rustdata-macros) | Procedural-macro crate that powers `#[derive(Entity)]`, `#[derive(QueryMethods)]`, `#[derive(Projection)]`, and `#[derive(SqlType)]`. Re-exported by `rustdata-core`; never add it directly. |
| [`rustdata-migrations`](crates/rustdata-migrations) | SQL-DDL transpiler: Dialect enum, type mappings, and multi-pass engine that converts canonical SQL into dialect-specific syntax (currently **SQLite** and **PostgreSQL**). |

## Quick start

```toml
# Cargo.toml
[dependencies]
rustdata-core = { version = "0.1", features = ["sqlite"] }   # or "postgres" / "mysql"
tokio = { version = "1", features = ["full"] }
sqlx = { version = "0.8", features = ["runtime-tokio", "sqlite"] }
```

```rust
use rustdata_core::{CrudRepository, Entity, QueryMethods, backends::Sqlite};

#[derive(Debug, Clone, Entity, QueryMethods)]
#[entity(table = "users", order_by = "created_at DESC")]
struct User {
    #[entity(id)]
    id: uuid::Uuid,

    #[entity(column = "username")]
    username: String,

    #[entity(column = "email")]
    email: Option<String>,

    #[entity(column = "age")]
    age: i32,
}

// Bring generated trait methods into scope.
use UserCrudQueryMethods as _;
use UserQueryQueryMethods as _;

#[tokio::main]
async fn main() -> anyhow::Result<()> {
    let pool = SqlxSqlitePool::connect("sqlite::memory:").await?;
    let repo = CrudRepository::<Sqlite, User>::new(pool);

    // Typed CRUD
    let saved = repo.insert(user).await?;

    // Typed query methods (generated by derive)
    let adults = repo.find_by_age_gt(21).await?;
    let sentinel = repo.exists_by_email_is_null().await?;
}
```

## Features

| Feature | Crate | Description |
|---|---|---|
| `postgres` | `rustdata-core` | Enables sqlx `postgres` dialect |
| `sqlite` | `rustdata-core` | Enables sqlx `sqlite` dialect |
| `mysql` | `rustdata-core` | Enables sqlx `mysql` dialect |
| `migration` | `rustdata-core` | Enables SQL transpilation re-exports from `rustdata-migrations` |

You must activate **exactly one** database dialect via Cargo features.

## Multi-dialect SQL transpiler

```rust
use rustdata_core::migration::transpile;

let sql = transpile(
    "CREATE TABLE users (id UUID PRIMARY KEY DEFAULT gen_random_uuid())",
    SqlDialect::Sqlite,   // ← target dialect
)?;
```

### Supported mappings

| SQLite | PostgreSQL | MySQL |
|---|---|---|
| `AUTOINCREMENT` | `SERIAL` / `BIGSERIAL` | `AUTO_INCREMENT` |
| `TEXT NOT NULL` | `VARCHAR NOT NULL` | `VARCHAR NOT NULL` |
| `REAL` | `DOUBLE PRECISION` | `DOUBLE` |
| `DEFAULT (datetime('now'))` | `DEFAULT now()` | `DEFAULT CURRENT_TIMESTAMP` |
